# ドット絵ワールド 仕様書

「歩けるドット絵の Web サイト」の試作一式の仕様です。4つの場面と、それらが使う共通エンジンでできています。

- **川辺のピクニック**（`picnic.html`）：川辺の木陰でピクニックをする場面。光・水面・木漏れ日の表現に力を入れた主役の場面。
- **江戸川のピクニック**（`edogawa.html`）：市川の江戸川河川敷を、国土地理院の標高・空中写真と OpenStreetMap から再現した場面。企画提案書の「身軽ピクニック」を描く。
- **ドット街さんぽ**（`town_3d.html`）：運河と広場のある小さな街。建物がサイトの各ページ（About・Works など）になる試作。
- **共通エンジン**（`engine/`）：描画・空と時間帯・実際の太陽・高さ画像の地形・遠景の影絵・構造物・揺れる草・歩行操作・当たり判定・水面・音・UI・書き出し。

最終更新：2026-10-18（江戸川のピクニックを追加）

## 2. 起動方法

ES モジュールを使うため、ファイルを直接開くのではなくローカルサーバー経由で開きます。

```bash
cd ~/picnic-site && python3 -m http.server 8790
```

- 入口：http://localhost:8790/
- ピクニック：http://localhost:8790/picnic.html
- 街：http://localhost:8790/town_3d.html
- スマホ実機で見る場合は `--bind 0.0.0.0` を付けて起動し、`http://<MacのIPアドレス>:8790/...` を開く。

~/Downloads に直接書き出したい場合は、別のターミナルでブリッジを起動します（起動していなければブラウザのダウンロードとして保存されます）。

```bash
cd ~/picnic-site && node tools/export_server.js --bridge-only
```

> `python3 -m http.server` はキャッシュを抑止しないため、`engine/` を書き換えた後は強制再読み込み（Cmd+Shift+R）が必要です。

## 3. 共通エンジン

### 3.1 描画の流れ（1フレーム）

1. 時間帯を更新（太陽・環境光・空・霧の色）
2. 歩行操作でカメラを動かす
3. 世界の動き（木の揺れ・アヒル・粒子・水面など）を更新
4. 水面の反射パス（水面で折り返したカメラ）と屈折パス（水を除いた景色）を描く
5. 本描画：低解像度の描画先に色と深度を描く。影はこのとき1フレームに1回だけ計算する
6. 法線パス：輪郭線用に法線を描く（空・粒子・草は除外）
7. 後処理（全画面シェーダー）：輪郭線 → にじみ → 光の筋（画面上・空気中）→ sRGB 変換 → 色ずらし → ディザ → 減色
8. CSS の `image-rendering: pixelated` で画面いっぱいに拡大

### 3.2 `pixel-renderer.js`（ドット絵レンダラー）

| 機能 | 内容 | 既定値 |
|---|---|---|
| 解像度 | 画面幅 ÷ `pixelScale`（最小 160×90）で描いて拡大 | `pixelScale` 3 |
| 縦長画面 | 縦FOVを広げて横約70°を確保（最大95°） | 横長時 FOV 62° |
| 輪郭線 | 1/深度の2階差分で手前に出た画素だけを暗く（×0.32）。法線の折れ目は明るく（×1.28）。32〜70m で薄れる | ON |
| 減色 | 43色の固定パレット、または各色N段階（`setQuantize(levels, dither)`） | パレット |
| ディザ | 4×4 Bayer | 0.075 |
| にじみ | 明るさ 1.25 を超える画素だけ、上下左右1〜2ドット＋斜めに広げる（`setBloom`） | 0（無効） |
| 色ずらし | 暗部・明部に色を足す（`setGrade({shadow, highlight})`） | 0 |
| 画面上の光の筋 | 太陽へ向かって空が見える割合を集める（`setSunRays`） | 0 |
| 空気中の光の筋 | 視線に沿って24回、影マップを調べ、日の当たる空気だけを光らせる。低い空気ほど濃い。太陽方向ほど明るい（`setVolumetric(light, 強さ, 色, 最大距離)`） | 0 |
| 書き出し用の固定解像度 | `setFixedSize({width, height})`。画面には比率を保って表示 | なし |
| 影 | `BasicShadowMap`（くっきりしたドット絵向きの影）、1フレーム1回だけ計算 | — |

### 3.3 `pixel-kit.js`

- `MASTER_PALETTE`：43色（街と共有）。夕方の空の中間色 `#ecdcb0` を含む。
- `PPM = 8`：テクスチャ密度（1mあたり8ドット）。
- `mulberry32(seed)`：再現性のある乱数。同じ seed なら同じ配置になる。
- `pixelTex(canvas)`：ニアレスト補間・ミップマップなしのテクスチャ。
- `createToon(levels)`：3段階トゥーン素材を作る関数（既定 `[115, 185, 255]`）。
- `glsl(src)`：シェーダーの `//` コメントを取り除く（日本語コメントを GPU に渡さない）。
- **`rampify(material)` と `RAMP`：素材ごとの3色塗り**（旧版の塗り方）
  - 光の当たり方を「真昼の日なた = 1」とした相対値で、影（<0.42）・中間（<0.70）・光の3段階に分ける。
  - 素材色に段階ごとの色（`RAMP.shadow / mid / high`、線形）を掛ける。影は青紫、光は黄みへ寄る。
  - 時間帯の光の色（彩度を6割）と暗さ（真昼の明るさ `RAMP.dayRef` との比、0.12〜1）は保つ。
  - 太陽と空で説明できない分の光（ランタン・街灯）は上に足す。発光はそのまま残す。
  - すでにある `onBeforeCompile` は壊さず、後ろに付け足す。

### 3.4 `time-of-day.js`

- `createLights(scene, { shadowSize, extent })`：影を落とす太陽（夜は月）と、空・地面からの環境光。
- `createTimeOfDay({...})`：時刻（0〜24）を9つのキーフレームで連続補間する。
  - 補間するもの：空の上・地平線の色、太陽の色と強さ、環境光の色と強さ、夜らしさ（0〜1）。
  - 太陽は 5:30 に昇り 19:00 に沈む。沈んでいる間は月の方向から照らす。
  - `sunZ`：太陽の通り道の南北のずれ（既定 +0.45 = 南側）。
  - `moonDir`：月の方向。
  - `fogSkyMix`：遠景（霧）の色を空の上の色へ寄せる割合。遠景が灰色に沈むのを防ぐ。
  - `auto`：自動で時間を進める（現実の15秒 = 街の1時間）。
  - 16:42 に「青みを保つ」キーフレームを入れ、夕方へ移る途中で空が灰色に減色されないようにしている。

### 3.5 `sky.js`

- 半径250の空の球。グラデーション、太陽の円盤とまわりの光、月、星（瞬きは6秒周期）。
- 遠景の山 28個、雲 9個。霧の影響を受けない単色シルエットで、色は時間帯で変わる。
- 空はカメラに追従する。

### 3.6 `player.js`（一人称の歩行操作）

| 入力 | 動き |
|---|---|
| WASD・矢印 | 移動（左右の矢印は横移動） |
| Shift | 走る（3.0 → 5.2 m/s） |
| マウスドラッグ | 見回す |
| クリック／タップ | その場所へ歩く。障害物は A* で避ける。行けなければ通知 |
| スマホ：画面左半分をドラッグ | 触れた位置が中心になるスティック。端まで倒すと走る |
| スマホ：画面右半分をスワイプ | 見回す |
| ホイール | おまかせ散策中、ルート上を進む・戻る |

- **おまかせ散策**：閉じた曲線（CatmullRom）に沿って自動で歩く。視線は進行方向へなめらかに向き、ゆっくり左右に揺れる。ドラッグで見回すと 2.5 秒後に正面へ戻る。
- **歩行の揺れ**：上下と左右の揺れ。一歩ごとに `onStep` で足音を鳴らす。
- **起伏**：`heightAt(x, z)` で足元の高さ（地形・橋）に沿って目線が上下する。
- **座る・立つ**：`setEye(h)` で目の高さをなめらかに変える。
- **`settle()`**：目の高さの補間と歩行の揺れを止める（ループ動画の録画前に使う）。
- **当たり判定**：x と z を別々に試して壁に沿って滑る。めり込んでいるときは脱出を許す。

### 3.7 `collision.js`

- `createCollider()`：四角と円を 2m 格子に登録して高速に引く。動くものは `addDynamic(fn)`。範囲外は `setBounds`。
- `findPath(collider, from, to, radius)`：0.25m 格子の A* で障害物を避ける経路を探し、見通しのよい区間は間引いて曲がり角だけを返す。

### 3.8 `water.js`（ドット絵の水面。旧版の作り方を移植）

| 要素 | 仕様 |
|---|---|
| 波 | 3つの正弦波（周期は6秒ループの整数倍）＋波紋。法線は 1/28 m の格子で求める（面ごとに切り替わるドット絵らしい水面） |
| 反射 | 水面で折り返したカメラから、水面より上だけを画面と同じ解像度で描き、波の法線で揺らす |
| 屈折 | 水を除いた景色を描き、波で歪めて川底を見せる（半透明で透かすのではない） |
| 水の色 | 深さ×1.65 で浅いエメラルド→深い青に沈める。透明度は 0.15〜0.88 |
| 時間帯の色 | 旧版の昼・夕・夜の色（浅い・深い・泡・川底の光）を重みで混ぜる |
| 川底の光 | 1/18 m の格子で、深さ 0.75m 未満の川底に描く（夜は弱く） |
| フレネル | 0.22 + 0.74 ×（1 − cosθ）^3.2（0.2〜0.92） |
| 岸の泡 | 深さ 0.05±0.02m 未満。寄せては返す |
| きらめき | 太陽（夜は月）の照り返し。指数 60、0.38 超で水色、0.62 超で白い芯（にじみの対象） |
| 波紋 | 最大6個。半径が 1.45 m/s で広がり、6m で消える |
| 深さ | 起動時に地形の高さから 256×256 の深さマップを一度だけ作る |

### 3.9 `capture.js`（書き出し）

- **PNG**：描画解像度を 320×180 に固定して1フレーム描き、4倍（1280×720）にニアレストで拡大して保存。
- **ループ動画**：320×180 で描き、1280×720 の画面を 60fps で `MediaRecorder` 録画。
  - 録画中は録画開始からの経過時間を場面の時計にする（0秒から始まり、周期の倍数で終わる）。
  - 形式は mp4（avc1）を優先し、なければ webm。ビットレート 12 Mbps。
- **保存先**：ブリッジ（127.0.0.1:18923）の `/health` が応答すれば `/save-blob` へ送って ~/Downloads に保存（.mp4 は ffmpeg で H.264 に変換）。応答しなければブラウザのダウンロードとして保存。
- 保存結果には「もう一度保存」のリンクを付ける。

### 3.10 `ui.js` / `ui.css`

- `bindButton`、`createToast`（数秒で消える通知）、`bindTimeControls`（時刻スライダー・表示・自動進行ボタン）、`fmtTime`。
- **`createAutoHide`**：操作がないと約2.5秒で `.fade` の付いた UI を消して風景だけにする。
  - マウスを動かすと戻る。移動キーを押している間とドラッグ中は消える。
  - メニューを開いている間は消さない。
  - スマホではドックだけ常に表示する（ホバーで呼び出せないため）。
- **ドック**（`#bar.dock`）：画面下中央の丸いボタン列。
- **設定メニュー**（`#menu`）と**書き出しパネル**（`#export`）：ドックのすぐ上に1つだけ開く。
- 画面の安全領域（ノッチ・ホームバー）に対応し、高さ指定はアドレスバーの出し入れに追従する。

### 3.11 `audio.js`

- 足音：橋は木の音、遊歩道は石の音、それ以外は草の音（ノイズを帯域フィルタで加工）。
- 水音：水辺までの距離に応じて音量を変える。
- 鳥の声：昼だけ、2〜7秒おき。
- 猫の鳴き声・チャイム：街で使う。
- 最初の操作で初期化する（ブラウザの自動再生制限のため）。

## 4. 川辺のピクニック（`picnic.html`）

### 4.1 コンセプトと絵作り

- 「初夏の午後、川辺でひと休み」。2000年代の携帯ゲーム機のようなドット絵の手触りに、今どきの光の表現を重ねる。
- **逆光の構図**：太陽の通り道を北側（`sunZ: -0.45`）にしている。いつもの視点（北の太鼓橋を眺める）が逆光になり、水面のきらめき・葉のすき間を通る光の筋・葉の縁の光が見える。旧版が美しく見えていた最大の要因で、それを意図的に再現している。
- **色**：固定パレットはやめ、各色32段階（ディザ 0.032）にしている。⚙️ メニューで43色パレットに切り替えられる。
- **素材ごとの3色塗り**（`RAMP`、線形の係数）：

| 時間帯 | 影 | 中間 | 光 |
|---|---|---|---|
| 昼 | 0.24, 0.30, 0.36 | 0.74, 0.77, 0.78 | 1.20, 1.15, 0.95 |
| 朝夕 | 0.30, 0.20, 0.36 | 0.82, 0.68, 0.66 | 1.28, 1.02, 0.78 |
| 夜 | 0.20, 0.24, 0.36 | 0.62, 0.70, 0.86 | 1.05, 1.00, 0.95 |

- **光の強さ**：

| 効果 | 強さ |
|---|---|
| 空気中の光の筋 | 昼 0.3 / 朝夕 1.1 / 夜 0.35（最大28m） |
| 画面上の光の筋（太陽が画面にあるとき） | 朝夕 0.9 |
| にじみ | 1.0 |

  - 「朝夕らしさ」は 18:24 ±1.3時間と 6:18 ±1.1時間で山になる重み。
- **6秒ループ**：波・川底の光・木の揺れ・草の揺れ・木漏れ日のちらつき・アヒル・本のページ・花びら・蛍・星の瞬きは、すべて6秒（`LOOP`）の整数分の1の周期で動く。動画の最初と最後がつながる。

### 4.2 地形（すべての高さの元データ `terrainHeight(x, z)`）

- 範囲は 64m 四方（メッシュは 200×200 分割、約0.3m間隔）。地面のテクスチャは 16ドット/m（1024px）。
- **川**：中心 x = −1.6 + sin(z×0.16)×1.4、半幅 2.3 + sin(z×0.31+1)×0.3。最深 0.85m。水面の高さ y = 0。
- **右岸**（ピクニック側）：岸の上の高さ 0.38m。川の中心から 7〜16m で丘が 3.2m 上がる。
- **左岸**（対岸）：岸の上の高さ 0.45m。5〜14m で丘が 3.5m 上がる。
- **上流・下流**：|z| 14〜26m で谷が 2m 上がる。
- **ゆるい起伏**：最大 ±0.06m。シートの周りでは消える。
- **シートの下**：シートとその周り30cmは完全に平ら（0.38m）。外側へ 1.8m かけてなだらかにつなぐ。
- **テクスチャの塗り分け**：川底（泥と小石）、岸（砂利）、草原（ノイズは控えめ。ときどき花）、丘（濃い草）、右岸の石畳の飛び石（0.8m おき、楕円、縁は暗く左上に光）。
- 地形の外側には、川底より低い y = −1.0 に野原の平面を置いている。

### 4.3 配置

| もの | 位置・仕様 |
|---|---|

### 4.4 木の作り方（全部同じ作り）

- 幹と枝は円柱。葉は塊（正二十面体を分割したもの）を数個組み合わせる。
- **葉の重心を幹の先端の真上にそろえる**：大きい塊ほど重く数えて自動でずらす。幹が枝葉の中央に来る。
- 葉の見た目：メッシュ自身の座標で、葉の房ごとの明暗のまだらを付ける（揺れても模様がずれない）。
- 揺れ：葉の塊全体を風で小さく揺らす（6秒ループ）。
- 以前あった柳（枝が垂れた木）は表現が他と揃わないため廃止し、同じ作りの木に置き換えた。

### 4.5 木漏れ日

- 影を描くパスでだけ葉を間引き、葉の影に本物のすき間をあける（`customDepthMaterial`）。地面・シート・小物に光の粒が落ちる。
- すき間は「光の向きから見た平面」上で決める。葉の塊の表と裏で同じ場所が抜けるので、地面まで光が届く。
- 粒の大きさは 0.26m（36%）と 0.85m（18%）の2種類。風で少しずつずれてちらちら動く（6秒ループ）。
- 夜は月明かりで同じまだら模様になる。
- 空気中の光の筋（3.2節）が、このすき間を通る光を空中の筋として見せる。

### 4.6 時間帯

- 開始時刻は 15:30。スライダーで 0〜24 時。⏩ で自動進行。
- ⚙️ メニューの切り替え：☀️ 昼下がり 15:30 / 🌅 夕暮れ 18:18 / 🌙 星と蛍 21:30。
- 夕暮れは逆光で手前が黒くつぶれやすいため、18:36 の環境光を強め（空 `#b08aa8`、地面 `#5a3a44`、強さ 0.9）にしている。
- 霧は 20〜60m（夜は14m手前まで）。色は地平線と空の上の色を 35% 混ぜる。

### 4.7 当たり判定と歩ける範囲

- 範囲は x −14〜14、z −16〜14。
- 川には入れない（足元が水際で止まる）。橋の上は渡れるが、欄干の外には出られない。
- 木の幹、シートの上の小物（円）にはぶつかる。シートの上自体は歩ける。
- 目の高さ：立ち 1.55m、座り 0.85m。半径 0.3m。

## 10. 設計上の判断と経緯

1. **レイマーチングから Three.js へ**：旧版は全画面シェーダーで全物体を毎ピクセル計算していたため、物を増やすほど重くなり、街の規模に広げられなかった。低解像度描画＋後処理でドット絵にする方式に変え、街とピクニックで同じエンジンを使う構成にした。
2. **共通エンジンの切り出し**：街の試作から、描画・時間帯・操作・当たり判定・音・UI を `engine/` に分けた。切り出しの前後で、街の当たり判定・入店・散策の結果が同じであることを確かめた。
3. **旧版の美しさの移植**：旧版と比べて光と水面が見劣りした原因は次の通りだった。
   - 固定パレット（当時42色）への減色でグラデーションが失われていた
   - 明るさを掛けるだけの陰影で、素材ごとの色の変化がなかった
   - 空気中の光の筋がなかった
   - 水面の波が粗く、きらめきが少なく、半透明で濁っていた
   - 旧版はきらめき用の太陽がカメラの向く北にあり、結果的に逆光の構図だった

   これらを移植し、太陽の通り道も北側にした。
4. **木漏れ日は描き足しではなく本物の影から**：最初は光の粒を地面に描き足していたが、光の向きと無関係だったため、影のパスで葉にすき間をあける方式に変えた。
5. **木陰の木と構図**：太陽の向きを変えたことに合わせて、木陰の木を移した。座った目線で太鼓橋をふさがない位置にし、幹を枝葉の中央に置いたうえで、樹冠を広げて影をシートに届かせた。
6. **風景優先のUI**：操作ボタンが景色を隠していたため、ドックと設定メニューにまとめ、操作がないと消えるようにした。

## 11. 既知の制約と未確認事項

- **スマホ実機は未確認**：表示と速さは、デスクトップのブラウザでスマホの画面サイズを再現して確かめただけ。描画パスが増えている（水の反射・屈折、空気中の光の筋）ため、古い端末では重い可能性がある。
- **フレームレート**：デスクトップでの CPU 時間は1フレーム約2.3ms（GPU 時間は未計測）。確認に使ったブラウザ画面が非表示のことが多く、実際の滑らかさは未確認。
- **音**：鳴らして聞いてはいない。
- **ループ動画**：最初と最後の差は花びら数ドット程度。H.264 の圧縮で最初のフレームの画質がわずかに異なる。
- **テスト動画**：~/Downloads に `riverside-picnic_1530_20261017-202219_6s.mp4`（2.2MB）が残っている（ブリッジなしの保存テストでブラウザが保存したもの）。不要なら削除してよい。
- **キャッシュ**：簡易サーバーはキャッシュを抑止しないため、エンジン変更後は強制再読み込みが必要。
- **街への未適用**：ピクニックで入れた3色塗り・空気中の光の筋・にじみ・風景優先UIは、街にはまだ適用していない。
