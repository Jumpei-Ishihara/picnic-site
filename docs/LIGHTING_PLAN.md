# ピクセルアートの光表現 改修方針

作成：2026-10-24。状態：初回試作後、なぎさ・picnicの画面効果を切戻し。木漏れ日は両ページで保持。対象：なぎさ（`nagisa.html`）・架空の川辺（`picnic.html`）。詳細と検証は [LIGHTING_DESIGN.md](LIGHTING_DESIGN.md)。

## 目的・表現の基準

自然な川辺を保ち、木漏れ日、柔らかな眩しさ、木々の間を通る光を少し豊かにする。暖かい日差し・涼しい影・空気遠近感を参考作品から得た表現上の方向とし、特定作品の内部描画技術の再現とは扱わない。画面全体の白い霞、日中の過剰な発光、常時見える光線を避ける。既存のドットの輪郭・季節・太陽方向・PNG/動画保存を保つ。

## 調査結果と採否

| 技術 | 現状と採用理由 | 今回の対応 |
|---|---|---|
| 影描画時の葉の穴（Goboに似た手法） | 共通樹木とpicnicが実装済み。小格子のランダム判定は細かい粒や境界の切替が目立ち得る | A：大小の連続した模様、緩い周期運動に変更。葉の見た目用メッシュを削らず、影だけに適用 |
| 影マップの安定化・PCF | 既に影中心をtexelに合わせている。全面的に軟らかい影へ変えるとドット絵の輪郭が変わる | 格子合わせを維持。影解像度の増加・PCF全面導入は見送り |
| HDRブルーム | 既存はRGB各成分の閾値と1〜2ドットの広がり。最後にclampするため明部の階調が失われる | B：輝度に基づく滑らかな抽出、既存の小さな光＋弱く広い光、明部のみの圧縮 |
| 影マップによる光線（レイマーチ） | 既存24サンプル。葉の穴と同じ影を使える | C：影範囲外の寄与を制限、短距離へ集中、距離減衰と控えめな前方散乱。加算だけで白くならない上限調整 |
| 画面上の放射状光線 | 既存20サンプルで空の見える割合を加算。葉の影の穴とは別情報 | C：太陽付近の補助効果へ弱める。画面端・遮蔽物での変化を確認 |
| 葉の疑似透過、局所霧、時間方向の蓄積 | 有効だが、材質・追加バッファ・残像など検討範囲が広がる | 今回は見送り。必要性を試作後に判断 |

## 実装範囲と順序

1. A：`engine/trees.js:createLeafKit` にオプションを追加。なぎさだけ有効化。picnicの葉の影処理を同じキットへ統合する。
2. B：`engine/pixel-renderer.js` に明示的な有効化設定を追加。なぎさ・picnicのみ新ブルームを使う。
3. C：同レンダラーの既存光線処理と、`realsite/look.js`・picnicの時間帯設定を調整する。共通lookはオプションで適用を限定する。
4. 同一条件の画像・GPU時間・エラー、PNG・動画、他ページの起動を検証する。

新しいシーン全体の描画パスやフレームごとの乱数を増やさない。写実版・江戸川・妙典系への表現変更、コミット・プッシュ・公開は今回の対象に含めない。

## 検証・採用条件

変更前後を同じブラウザ・夏・1280×720表示・320×180描画・停止時刻で比較。昼、樹冠を見上げる構図、夕日、夜を対象にする。固定時間の比較と動画の動きの確認を区別する。白飛び・遠景の消失・光の壁抜け・木漏れ日のちらつき・視点/画面端の不連続を確認する。

GPUタイマが使える場合は実測し、同期待ちを含むCPU時間と区別する。既存24/20サンプルを増やさず、追加負荷が大きければ広いブルームの参照数・光線設定を再調整する。数値上の明るさ指標だけで自然さを合格扱いにしない。未検証の端末や測定不能な項目は詳細設計に残す。

## 夕景比較による方針変更（2026-10-24）

なぎさの光芒・明部圧縮・ブルーム・空中光は旧方式へ戻す。木漏れ日のみ改善を保持する。試作で光芒の減衰が重なり、日没直前の光の広がりが失われたため。今後は元の夕景の明るい裾と黄白色の芯を維持し、各効果を独立比較する。[原因分析・検証結果](SUNSET_REVIEW.md)。picnicは今回の切戻し対象に含めず、同種の抑制設定を今後の見直し候補として残す。


## picnicの追認・切戻し（2026-10-24）

picnicも夕景の劣化を8条件の比較で確認し、新しいブルーム・明部圧縮・光芒・空中光を旧方式へ戻した。木漏れ日・影とカメラの更新順・6秒周期の修正を保持する。従って上記「picnicは切戻し対象外」はなぎさだけを調べた時点の履歴であり、現在は両ページとも画面効果は旧方式。[原因・検証結果](LIGHTING_DESIGN.md#picnic夕景の確認切戻し2026-10-24)。
