# なぎさポニーランド 改修方針（2026-10-27）

## 調査と根拠

公開中のポニー視点、`realsite/nagisa-facilities.js`、施設生成元 `tools/geo/build_nagisa.py`、`scenes/nagisa/scene.json` を照合した。

- [国土地理院の空中写真](https://maps.gsi.go.jp/#18/35.649700/139.881500/&base=seamlessphoto&ls=seamlessphoto&disp=1)：北の馬場、南の円形囲いと建物を確認。文学館建設前の画像が含まれる。閲覧年を撮影年とみなさない。
- [運営財団の施設案内・乗馬・乗り場・全景写真](https://www.edogawa-kankyozaidan.jp/pony/nagisa/)：砂の走路、茶色の柵、芝の放牧場、緑の乗り台、引き手と手綱、馬の輪郭を参照。写真の撮影日は不明。敷地面積5,000m²は公式値だが個々の施設寸法は推定。
- [江戸川区の利用案内](https://www.city.edogawa.tokyo.jp/e066/kuseijoho/gaiyo/shisetsuguide/bunya/koendobutsuen/nagisaponyland.html)：通常の乗馬時間、夏季の午後休止を確認。実際の休園・臨時運用を再現するアプリではない。
- [University of Kentucky / Extension Horse Walk](https://horses.extension.org/horse-walk/)：常歩は4拍子。右後→右前→左後→左前の循環に合わせる。

現地の実測図や最新の全方向写真は得られていない。円形囲いの用途、ヤギの位置、各寸法、在籍頭数・個体名は確定しない。推定配置を大きく移し替えず、確認できる矛盾を先に修正する。

## 対応順序

| 段階 | 問題と該当実装 | 方針・理由 |
|---|---|---|
| A | `createPonyRing` の内柵がstyle:noneでも生成される。生成元とJSONの古い説明が円形囲いを乗馬場所と断定 | 柵のない走路は内柵・中央構造物も生成しない。乗馬は東の砂スペース、円形囲いは別施設として記述。配置・衝突判定は既存施設データを共用 |
| B | `makeQuadruped` はヤギと共用の直方体、耳・蹄なし、頭のみ移動 | ポニー専用モデルに分離。胸・腰・傾いた首・口吻・耳・蹄を追加。首支点に頭とたてがみを従属。静止個体に斑模様を追加 |
| C | 対角脚の同時振り、接地拘束なし | 4拍子、支持期/遊脚期、円周の移動距離と連動した足位置、2節の解析的IKで接地を維持。地形の高さを蹄ごとに参照 |
| D | 引き手・乗り手が独立、手綱なし | 頭絡の先から引き手の手へ手綱を接続。鞍を基準に座位を維持。待機・採食は首全体を動かす |
| E | 個体差と短い保存ループの競合、負荷未測定 | 周回3頭の外観をそろえ6秒の置換対称性を維持。尾は空間の位相と同期。静止個体で毛色差を表現。描画負荷・継ぎ目・実ファイル保存を検証 |

## 採用する制約

標準の6/12秒保存と風景全体の6秒周期を維持する。周回する3頭の異なる毛色・名前と18秒保存は今回採用しない。完全な乗降・厩舎移動の状態機械は短時間ループと両立しないため対象外とする。10頭という既存の場面内頭数は実在籍頭数を表さない演出であり、実在個体の複製という説明はしない。

描画品質は通常の320×180相当の画面で判断し、接写だけの細密化を避ける。共有ジオメトリと材質、静的部品の結合を使う。夕景のブルーム・光線・トーン調整には変更を加えない。

## 検証と受入基準

- 不要な内柵がないこと、走路と乗り台・待機個体が交差しないこと。
- 四肢の着地順、支持中の世界座標の固定、地面との隙間、首・鞍・手綱の接続を数値と画像で確認。
- 0/6/12秒と6秒直前・直後を比較。モデル単体と描画結果の両方を検証し、動画の最終フレームと先頭フレームの時間差を考慮する。
- 同じ視点・時刻・解像度で改修前後の描画回数、三角形数、フレーム時間を比較。PNG・6秒動画の実保存と復帰を確認。
- 結果・証跡・未検証事項は [詳細設計](PONY_DESIGN.md) に記録。

## 初回の実施結果（2026-10-27）

段階A〜Eを実装・検証した。周回の外観統一、円形の推定走路の維持、独立した耳の動きや完全な乗降動作の見送りは上記の制約として明示する。通常視点の描画回数は1,726→1,712、蹄の接地4,320点で到達限界の補正なし。51件の回帰テストとPNG・6/12秒MP4の実保存に成功。録画初期化の追加修正と、圧縮・可変フレーム間隔を含む動画の評価限界は詳細設計に記録した。

## 再レビュー後の結果（2026-10-27）

初回の地形高さへの一致だけでは実描画面への接地を確認できていなかったため、走路と近景地形の三角形に合わせて修正した。手綱と可視の手の接続、白い待機個体の模様、板状の斑模様、静止中の不要な脚更新も修正。回帰テストは56件成功。実走路の支持2,784点、待機・放牧28点を独立したレイで確認し、0/6/12秒の影・反射を含む描画が一致した。現在の通常視点の描画回数は1,726回、中央値5.00ms。PNGと6/12秒MP4も再保存した。[再レビューの詳細・残る制約](PONY_DESIGN.md)、[最新証跡](pony-validation/review/index.html)を参照。
